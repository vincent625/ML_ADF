# Roadmap

1. Review action boundaries and ADF-development relevance. Resolve the 197 label-quality flags in a new campaign without changing the original frozen study.
2. Add a reviewed schema adapter between requirements matrices and workbench drafts. Preserve missing fields, source provenance and pending decisions.
3. Improve artifact matching and verification: filename boundaries, immutable revisions, actual bytes, hashes, baseline values and variant scope.
4. Collect independent reviewed actions and confirmed historical cutoffs, then run a strict held-out evaluation with a new frozen campaign.
5. Obtain complete approved inputs and core build tooling before extending the narrow local operations to genuine ADF assembly.
6. Connect reviewed acceptance criteria to existing software and scientific tests; keep physical validation and release approval explicit.
7. Run a matched manual/assisted timing pilot. Measure active effort, waiting, setup and rework separately. Set improvement targets only after a measured baseline exists.

Upstream's original 50% improvement and weeks-to-days targets are retained as proposed goals in `docs/upstream/05-roadmap.md`; they are not achieved results.
