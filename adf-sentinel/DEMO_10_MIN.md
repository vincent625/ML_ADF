**Reset the presentation:** `8 · Export` → **Reset presentation view**. It does not delete evidence, weights, predictions or audit records.

**Restart the local server:** stop the current server, then:

```bash
cd /rhome/yanzhu/ML_ADF
PYTHONPATH=adf-sentinel adf-sentinel/.venv/bin/python -m adf_sentinel serve --port 8876
```

**Prediction button unavailable:** use the already recorded receipt and say “recorded prediction replay.” If no receipt exists:

