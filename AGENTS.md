ADF Sentinel — Codex Instructions

Project Context

ADF Sentinel is a hackathon project.

Before making changes, read:

README.md

docs/01-vision.md

docs/03-architecture.md

docs/04-current-status.md

docs/05-roadmap.md

Treat these files as the shared project context. Do not assume undocumented features already exist.

Development Rules

Follow the established architecture and coding conventions.

Prefer small, incremental changes.

Do not introduce unnecessary dependencies.

Write tests for new functionality where practical.

Never commit API keys, credentials, or sensitive data.

Ask before making major architectural changes.

Collaboration

Use feature branches for development.

Avoid modifying files owned by another active task without coordination.

Record important design decisions in docs/06-decisions.md.

Keep the roadmap and current status accurate.

Session Handoff

At the end of a significant coding session:

Summarize what was implemented.

List files changed.

Record tests executed and results.

Identify remaining issues and blockers.

Recommend the next task.

Save the summary under codex/handoffs/.

Do not mark tasks complete unless their acceptance criteria are satisfied.
