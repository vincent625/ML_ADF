# Source and evidence provenance

This handoff combines a requirements traceability component with the local ADF
Sentinel historical study, review workbench, and IRS-65265 synthetic evidence lab.
Supporting component documentation is preserved in `docs/upstream/`.
Repository identifiers have been omitted from this distribution.

No license or notice file was included with the requirements component. This
package does not add an open-source license or change ownership of component
code, internal reference material, or source assets.

Original local evidence stores and the frozen campaign remain separate. Published
results retain their dates and scope. Some copied report text is sanitized; the
copy manifest records changed-file hashes. Historical receipts describe the
original execution environment and are not fresh verification of every private
input on a new machine. See `PACKAGE_SCOPE.md` for included and omitted content.
