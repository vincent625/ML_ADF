# IRS-57322: maxSamplePerPool parameter was wrong in OCAv3 Gx6.8 w6.0.0 ADF

[Open source issue](https://lsg-thermofisher.atlassian.net/browse/IRS-57322)

Retrospective review aid. Proposed labels are unreviewed. No new approval or execution is inferred.

## Current snapshot

Created: 2025-01-11T02:19:42.000+0530; updated: 2025-01-22T07:22:51.000+0530

The maxSamplesPerPool parameter, which is new for Gx6.8 ADFs, was set mistakenly to 6.

This maxSamplesPerPool parameter needs to be set to 4 for OCAv3 Gx6.8 w6.0.1 ADF, for Gx5 chip assays, meaning the workflow is for 4 reaction runs.

This parameter needs to be updated for both "primer_profile_RNA" and "primer_profile_DNA".

We should follow OCAplus combo ADF rule to exclude the maxSamplesPerPool parameters from UI downloadable json file to avoid accidental user mistake.
